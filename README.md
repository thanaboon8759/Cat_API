# Cat_API

A beautiful web application that displays cat images and breed information using [The Cat API](https://thecatapi.com/).

## Features

- 🎲 **Random Cats**: Browse random cat images from around the world
- 🏆 **Breed Information**: View cats with detailed breed information
- 📊 **Statistics**: Track the number of cats viewed, available breeds, and current page
- 📱 **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- 🖼️ **Interactive Gallery**: Click on any cat image to view it in full size

## Live Demo

Simply open `index.html` in your web browser to start exploring amazing cats!

## Usage

### Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/thanaboon8759/Cat_API.git
   cd Cat_API
   ```

2. Open `index.html` in your web browser:
   - Double-click the file, or
   - Use a local server (recommended):
     ```bash
     python3 -m http.server 8080
     ```
   - Then navigate to `http://localhost:8080`

### Features Guide

- **Random Cats Button**: Load 10 random cat images
- **Show Breeds Button**: Load cats with breed information and descriptions
- **Load More Button**: Load additional cats based on your current selection
- **Click on any cat card**: Opens the full-size image in a new tab

## API Integration

This project uses [The Cat API](https://thecatapi.com/) to fetch cat images and breed data. The API key is included in the code for demonstration purposes.

### API Features Used:
- Random cat image search
- Breed-filtered searches
- Pagination support
- Breed information retrieval

## Technology Stack

- **HTML5**: Structure and semantic markup
- **CSS3**: Styling with gradients, flexbox, and grid
- **JavaScript**: Async/await API calls and DOM manipulation
- **The Cat API**: Data source for cat images and breeds
